# RoverLink НСУ — отдельное приложение оператора

Программа для Windows 10/11 x64. Версия 0.1.0-beta2:
поиск RoverLink в сети, RTSP H.264/H.265, выбор HID-пульта,
назначение и калибровка каналов, передача управления по MAVLink.
Установщик содержит видеокомпоненты и работает без скачивания зависимостей.

Проект развивается отдельно от бортовой станции. Программные проверки
выполнены; реальные пульт, машина и чистая Windows требуют проверки.
Карта, редактор миссий и полный редактор параметров пока не реализованы.
