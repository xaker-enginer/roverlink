# RoverLink НСУ — отдельное приложение оператора

Актуальная рабочая версия — **1.3.0**, приложение для Windows.

- Подключение пульта через DirectInput.
- Передача управления по MAVLink v2.
- Переключение камер из приложения.
- Единое подключение к станции и обновлённый интерфейс.

11 ноября 2026 года владелец проекта подтвердил испытание версии 1.3.0
на рабочей машине в поле. Проверка относится к использованной комплектации;
для другого пульта, камеры и компьютера совместимость проверяется отдельно.

НСУ развивается отдельно от бортовой станции. Номер версии приложения
не является номером прошивки. Старое описание 0.1.0-beta2 историческое
и не определяет возможности новой программы.
